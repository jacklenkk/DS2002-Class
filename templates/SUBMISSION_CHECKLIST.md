# Submission Checklist

Run through this every time you submit a lab or project.

## Before you submit

- [ ] **Restart kernel** and **Run All** — notebook executes top-to-bottom with zero errors
- [ ] Outputs are present (plots render, tables print, results show)
- [ ] All `TODO` cells are completed
- [ ] Markdown cells explain what you did and why (at least between major steps)
- [ ] No leftover debug cells or dead code
- [ ] File is named correctly: `YYYY-MM-DD — Topic — Type.ipynb`
- [ ] File is in the correct `notebooks/` subfolder

## Push to GitHub

- [ ] `git add`, `git commit` with a clear message (e.g. `Lab 04: Pandas challenge`)
- [ ] `git push`
- [ ] Confirm the file shows up on GitHub in the browser

## Submit in Canvas

- [ ] GitHub repo link
- [ ] Kaggle/Colab notebook link (if the assignment asks for it)
- [ ] For projects: project README included in the repo

## Studio checkpoint only (participation)

- [ ] Ran the checkpoint cell at the bottom of this week's Studio notebook
- [ ] Submitted **individually** in Canvas (`Studio Checkpoint — Week X`) by Thursday 11:59pm ET
- [ ] Pasted output or uploaded a screenshot — one or two sentences is enough

## Projects only

- [ ] Reflection questions answered (every team member contributes)
- [ ] ≥6 visualizations, all labeled
- [ ] API source cited with base URL
